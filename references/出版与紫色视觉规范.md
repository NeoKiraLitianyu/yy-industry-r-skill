# 出版与紫色视觉规范

## 目标

把证据工程结果转成可直接交付投资团队、产业专家和被投企业讨论的正式出版物。输出不是网页演示稿，而是 A4 阅读、打印、归档和引用都稳定的研究报告。

## 固定视觉令牌

|用途|颜色|
|---|---|
|主紫|`#4B2E83`|
|辅助紫|`#7456A8`|
|浅紫表面|`#F4F0FA`|
|纸张底色|`#FAF9F7`|
|正文墨色|`#211B2B`|
|次级文字|`#706779`|
|分隔线|`#DED6E8`|

主紫只用于封面几何、章节线、表头、关键判断和 callout 左边线。正文以墨色为主，浅紫只承担分组。禁止高饱和渐变、厚重阴影、装饰性照片、Emoji 和远程字体。

## A4 与信息结构

- `@page size: A4`，正文保留稳定页边距、孤行控制和表头重复。
- 封面、目录、执行摘要、22 章正文、Mapping、事实矩阵、来源附录按页级结构组织。
- 长 URL 和原始文件路径必须可换行；图、表、callout 尽量避免跨页断裂。
- 图表以离线 SVG 内联 HTML，同时导出独立 SVG；禁止脚本、`foreignObject`、远程图片和外链字体。
- 事实、图表和模型均显示 `as_of`、依据与事实锚点。内部测算必须出现“内部模型假设”。

## PDF 验收

使用 Edge/Chrome 列表参数无头打印，不拼接 shell 命令。验收至少包括 `%PDF-` 文件头、20 页、合理体积，以及“半导体膜材”“行业 Mapping 与投资机会地图”“数据来源、原始素材与引用清单”可抽取。验收失败不得把 PDF 作为正式成品交付。
