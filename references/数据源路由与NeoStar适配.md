# 数据源路由与 NeoStar 适配

## 两种运行模式

- 独立模式：公开网页、用户导入、本地文件和可选 Yixin OpenAPI。不得假定存在 NeoStar、WorkBuddy 或任何 MCP。
- NeoStar 增强模式：额外读取星图数据库、一级市场知识库，并在显式授权后调用 TDX MCP。增强源失败时必须回到独立模式，不中断其他通道。

## 路由顺序与能力边界

|顺序|通道|主要能力|边界|
|---:|---|---|---|
|10|Yixin `search`|研报、学术、公告、专家与网页发现|结果是发现线索；原文未归档前不算正式证据|
|20|TDX MCP|中国券商研报、公司公告、上市可比数据|按调用计费，默认关闭；行业研究仅用研报和公告，不拉无关盘口|
|30|NeoStar 本地|星图产业认知、一级市场知识库、历史摄入资料|本地结论仍需追溯其原始来源；无来源卡片只作研究线索|
|90|全球公开源|政府、协会、公司、学术、标准、券商与咨询机构原文|不得绕过登录、验证码、付费墙或 robots 限制|

所有通道输出相同字段：原始链接、标题、来源类型、地区、语言、发布日期、可信度、发现通道和原始元数据。按规范 URL 去重；同一原稿的多个发现通道合并，不增加独立来源数。

## NeoStar 现有能力的复用位置

- `yixin-api`：复用 `search` 的 report/academic/announcement 三类搜索；`fin_db` 仅用于上市可比公司财务与估值补充。
- TDX：复用 `wenda_report_query` 与 `wenda_notice_query`；`TDX_MCP_ENABLED` 或命令行 `--启用-tdx` 是计费门。
- 星图：读取 `星图数据库/产业图谱研究` 与 `星图数据库/NeoData/industry`，保留原文件路径和命中词。
- 一级市场：读取 `一级市场机会/_知识库`，产物归入一级市场行业库，投资报告遵循一级域证据与 memo 边界。
- 统一数据路口：遵循 MCP → HTTP/公开源 → 本地缓存 → DEGRADED；每次运行保存 `数据源回执_*.json`。

## 降级与审计

每个适配器必须独立回执：适配器、状态、候选数、错误、时间。无密钥、断线、超时、额度不足和计费源未启用均记为“降级”，不得伪装为空结果。原始密钥不得进入回执、候选清单或报告。

TDX 每次运行默认最多 6 个工具调用。只有用户明确启用时才调用；未启用不属于研究失败。Yixin 发生 401/403/429 时记录状态并继续公开源。

## 独立分发要求

代码不得 import NeoStar 内部模块。NeoStar 适配通过目录扫描、环境变量或标准 MCP/HTTP 契约实现。复制 Skill 文件夹到另一台机器后，`初始化`、本地导入、公开源采集、归档、解析、验证、Mapping 和报告必须可运行。
